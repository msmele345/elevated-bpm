# Field Guide — The v3 Deck

**Covers:** Elevated BPM v3.0 · Groove, Bank & Acid  
**Level:** Any — read the page for the feature you are about to use  
**Primary visual aid:** [Open the HTML guide](index.html)

## What this is

A reference for everything v3 added to the Deck. The [First Groove](../01-build-the-pulse.md) course teaches you to make techno one sitting at a time; this guide tells you where each new control is and what it does. Read a page, then go and try the control while the loop plays.

You do not need to read it in order. Every new setting starts at the sound the Deck already made — swing 50%, every Level at 0.0 dB, Env Mod 0%, no accents or slides, slots B–D empty — so nothing changes until you touch it.

## Where everything sits now

Top to bottom, the Deck reads:

1. Header — the Elevated BPM name and the **Share ▾** menu
2. A shared-beat strip or a link error, only when one needs your answer
3. **Transport strip** — Play, Tempo, BPM, Swing, slots A–D, Copy, Clear. It stays pinned to the top of the screen.
4. **Curriculum** line — track buttons, progress, the current lesson, **Path ▸**
5. The lesson card
6. Drum Machine
7. Sampler
8. Bass Line
9. Chord Stab
10. Master — scope, Filter and Drive macros, FX

On a fresh load at 1280×720, Play, the tempo and all five drum lanes are on screen before you scroll.
